Float and Clear Properties

Illustrates floating elements left and right with clearfix to prevent container collapse.

Live CSS Demonstration css-08.html
float: left
float: right

Float removes an element from normal flow, placing it along the left or right of its container. Text and inline elements wrap smoothly around it until a clear or clearfix rule resets the boundary.

• clear: both ensures subsequent content begins beneath the floated boxes.
